 🎮 Pixelman Adventure

A retro-style 2D platformer inspired by Super Mario, built with Python and Pygame.  
Run, jump, collect coins, defeat enemies, and reach the goal across colorful pixel worlds! 🌈  

---

 🧱 Features

- Classic side-scrolling gameplay  
- Smooth physics and tile collisions  
- Coins, enemies, and goal flag  
- Camera following system  
- Expandable level system  
- Clean, easy-to-read codebase for beginners

 ⚙️ Installation & Setup

 Requirements
- Python 3.8 or later  
- Pygame (`pip install pygame`)

### Steps
1. Clone this repository:
   ```bash
   git clone https://github.com/your-username/Pixelman-Adventure.git
   cd Pixelman-Adventure

2. Install dependencies:

pip install pygame


3. Run the game:

python main.py
