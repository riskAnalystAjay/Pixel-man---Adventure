Contributing to Pixelman Adventure

🎉 Thank you for considering contributing to **Pixelman Adventure!**  
We welcome all contributions — whether it's fixing bugs, improving code, or designing new levels.

---

## 🧩 How to Contribute

1. **Fork** the repository  
2. **Create** a new branch for your feature or fix:
   ```bash
   git checkout -b feature-newlevel

3. Commit your changes:

git commit -m "Added new coin animation"


4. Push to your fork:

git push origin feature-newlevel


5. Submit a Pull Request 🎯




---

💡 Suggestions You Can Contribute

Add new levels or enemies

Improve art and sound effects

Fix physics or collision issues

Optimize performance

Update documentation or README



---

🧠 Code Guidelines

Keep your code clean, readable, and commented.

Follow Python’s PEP8 style guide.

Test your feature before submitting a pull request.



---

❤️ Community Values

Be respectful, patient, and helpful.

Credit others’ work and ideas.

Keep communication friendly and collaborative.
